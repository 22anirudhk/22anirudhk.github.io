Guidance + sampling

1.1 Forward Process

Forward noise follows the spec recipe: pick timestep t, scale the clean image by \(\sqrt{\alpha_{\text{cum}}[t]}\), add Gaussian noise scaled by \(\sqrt{1-\alpha_{\text{cum}}[t]}\), and repeat for each t. The t=250/500/750 plots show the smooth march toward pure noise.

1.2 Classical Gaussian Denoising

As a control experiment from the spec, sweep Gaussian kernel/sigma in torchvision to push the noisy inputs back toward clean. Blurs dampen high-frequency noise but quickly smear edges at higher noise levels, underscoring why learned reverse steps are needed.

1.3 One-Step Denoising

Run one reverse step exactly as in the handout: pass the noisy image, timestep, and neutral prompt embedding to stage_1.unet, take the first three channels of its output as the noise estimate, and reconstruct with the closed-form update (Eq. A.2). It cleans light noise but falters as t increases, which is why the iterative schedule is also shown per the deliverable.

1.4 Iterative Denoising

Start at t=990 and stride down by 30 to 0. At each step: run the UNet to predict noise, compute the next cleaner image using the alpha_bar weights (signal vs. noise blend), add the prescribed variance term, then continue to the next timestep. This mirrors the spec update; the final is sharper than one-step or Gaussian baselines.

1.5 Sampling from Noise

Start from pure Gaussian noise at the highest timestep and run the same iterative loop with the neutral prompt. This is pure generation without CFG to keep diversity; the spec calls for five samples. Prompt used: “a high quality photo.”

1.6 Classifier-Free Guidance

Run the UNet twice per step: once with the prompt, once with an empty prompt. Mix the noise predictions as noise_guided = noise_cond + cfg * (noise_cond − noise_uncond) with cfg=7, then apply the usual reverse update. This strengthens prompt adherence while reducing diversity. Conditional prompt: “a high quality photo”; unconditional prompt: empty (per spec).

1.7 SDEdit: Image-to-Image

Add controlled noise to an input image, then denoise with the neutral prompt using the iterative loop. Higher starting indices give the model more freedom to alter structure before projecting back.

1.7.1 Web + Hand-Drawn Edits

Apply the same SDEdit loop to one web image and at least two doodles after center cropping/resizing to square (deliverable requirement). Low noise keeps the original recognizable while higher noise forces the model to hallucinate more detail.

1.7.2 Inpainting

At every reverse step, clamp unmasked pixels back to the original image re-noised for the current t and let the model redraw only the masked hole. Steps: run a reverse step, replace unmasked regions with the source image plus matching noise for that timestep, then proceed to the next t. This keeps context fixed while filling the gap.

1.7.3 Text-Conditional Edits

Same SDEdit pipeline but swap in new prompts so the projection is steered toward the text. More initial noise yields more dramatic prompt-driven changes to the original.

1.8 Prompt-to-Prompt Illusions

At each step, denoise both the image and its 180° flip with two different prompts, average their noise predictions, and continue the reverse chain. Upright and flipped views emphasize different prompts. Recipe: run UNet on the image with prompt A, on the flipped image with prompt B, flip B’s noise back, average the two noises, then apply the reverse step.

1.9 Hybrid Images

Split the predicted noise into low-pass and high-pass via Gaussian blur, keep lows from one prompt and highs from another, then combine for the reverse update. Tiny thumbnails hint at the low-frequency read while the full images show the merged hybrid. Low↔high pairs: a photo of a blueberry muffin ↔ a photo of a dog, a photo of a face ↔ a photo of a waterfall, a photo of a skull ↔ a photo of a polar bear. Steps: UNet with prompt A → blur for low-pass; UNet with prompt B → subtract blurred to get high-pass; add lows + highs, then run the reverse update.

A shallow UNet trains with MSE on noisy/clean pairs; every batch is re-noised each epoch so the model learns the mapping, not the specific corruption. 1.2.3 Denoising Pure Noise

Retrain the same UNet to map pure noise toward digits. The outputs look like an average of several digits; MSE likely pushes predictions toward the dataset mean when there is no conditioning signal.

2.3 Time-Conditioned Flow Matching

Inject normalized time into the UNet via small FC blocks, sample a random t each batch, and train the network to predict the flow back toward clean data. Training loop: pick an image x, draw a t, create x_t via linear interpolation with noise, ask the UNet to predict the flow vector, and step optimizer. Sampling starts from noise at t=1 and repeatedly uses the predicted flow to move toward digits as t lowers. Spec architecture/equations/loops are below. 

// t normalized to [0, 1]
fc1_t = FCBlock(...); fc2_t = FCBlock(...);
t1 = fc1_t(t); t2 = fc2_t(t);
// modulate decoder features by time
unflatten = unflatten * t1;
up1 = up1 * t2;
// continue through the UNet heads

2.6 Class-Conditioned Sampling

Add one-hot class conditioning with dropout (10% of the time, class conditioning vector was set to 0) so classifier-free guidance is possible; sampling uses cfg to bias toward the requested digit. During training, sometimes drop the class vector to enable CFG. During sampling, run conditional and unconditional passes, blend with a guidance scale, and step the reverse process. Results improve faster than time-only. Spec CFG sampling loop is below. CFG scale=5.0. 

// t normalized, c one-hot (with 10% drop to zeros)
fc1_t = FCBlock(...); fc2_t = FCBlock(...);
fc1_c = FCBlock(...); fc2_c = FCBlock(...);
t1 = fc1_t(t); c1 = fc1_c(c);
t2 = fc2_t(t); c2 = fc2_c(c);
unflatten = c1 * unflatten + t1;
up1 = c2 * up1 + t2;
// forward pass continues; for CFG sampling:
// noise_guided = noise_cond + cfg * (noise_cond - noise_uncond)

Scheduler Ablation

Same class-conditioned setup but remove the LR decay. Curves and grids show how training behaves without the scheduler. To compensate for the lack of scheduler, the learning rate was adjusted to 2e-3 to mimic an "in the middle" learning rate value that would have been reached had the scheduler still been present.

Reflection

Diffusion felt more forgiving than NeRFs: after wiring stride, variance, and CFG correctly, swapping prompts or masks produced stable outputs. Inpainting and SDEdit were the most satisfying because the same reverse loop could handle edits with minimal code change. For flow matching, conditioning on time and class made the guidance math concrete and visibly sped convergence.
