1.1 Forward Process

Forward noise follows the spec: scale the image by \(\sqrt{\alpha_{\text{cum}}}\) and add Gaussian noise with \(\sqrt{1-\alpha_{\text{cum}}}\) at each chosen timestep. This exactly matches the provided forward() equation; the t=250/500/750 plots show the smooth march toward pure noise.

1.2 Classical Gaussian Denoising

As a control experiment from the spec, sweep Gaussian kernel/sigma in torchvision to push the noisy inputs back toward clean. Blurs dampen high-frequency noise but quickly smear edges at higher noise levels, underscoring why learned reverse steps are needed.

1.3 One-Step Denoising

Run one reverse step exactly as in the handout: pass the noisy image, timestep, and neutral prompt embedding to stage_1.unet, take the first three channels of its output as the noise estimate, and reconstruct with the closed-form update (Eq. A.2). It cleans light noise but falters as t increases.

1.4 Iterative Denoising

Use a strided schedule from 990→0 (step 30). Each step predicts noise, blends signal/noise with the alphas, and reintroduces variance with the helper so the chain stays on the diffusion trajectory. This follows the strided timetable and update in the spec; the final result is noticeably sharper than the one-step or Gaussian baselines.

1.5 Sampling from Noise

Start from pure Gaussian noise at the highest timestep and run the same iterative loop with the neutral prompt. This is pure generation without CFG to keep diversity.

1.6 Classifier-Free Guidance

Two UNet passes per step—one with the prompt, one empty—and blend their noise estimates with cfg=7.5. Guidance tightens alignment to the text while sacrificing some variation.

1.7 SDEdit: Image-to-Image

Add controlled noise to an input image, then denoise with the neutral prompt using the iterative loop. Higher starting indices give the model more freedom to alter structure before projecting back.

1.7.1 Web + Hand-Drawn Edits

Apply the same SDEdit loop to web images and doodles after center cropping/resizing to square. Low noise keeps the original recognizable while higher noise forces the model to hallucinate more detail.

1.7.2 Inpainting

At every reverse step, clamp unmasked pixels back to the original image re-noised for the current t and let the model redraw only the masked hole. This keeps surrounding context fixed while filling the gap.

1.7.3 Text-Conditional Edits

Same SDEdit pipeline but swap in new prompts so the projection is steered toward the text. More initial noise yields more dramatic prompt-driven changes to the original.

1.8 Prompt-to-Prompt Illusions

At each step, denoise both the image and its 180° flip with two different prompts, average their noise predictions, and continue the reverse chain. Upright and flipped views emphasize different prompts.

1.9 Hybrid Images

Split the predicted noise into low-pass and high-pass via Gaussian blur, keep lows from one prompt and highs from another, then combine for the reverse update. Tiny thumbnails hint at the low-frequency read while the full images show the merged hybrid.

1.1 Noising Process

Each MNIST digit is corrupted with Gaussian noise at a sampled scale so the denoiser sees a range of inputs. Visualizing multiple σ values sets expectations for what the UNet must undo.

1.2 Single-Step Denoiser

A shallow UNet trains with MSE on noisy/clean pairs; every batch is re-noised each epoch so the model learns the mapping, not the specific corruption. Loss curves track convergence, and test samples show denoising at σ=0.5.

1.2.2 Out-of-Distribution Noise

After training on σ=0.5, push the same test digit through other σ levels to gauge how well the single-step model generalizes beyond its training noise.

1.2.3 Denoising Pure Noise

Retrain the same UNet to map pure noise toward digits. Early epochs converge toward blurry class means; later epochs sharpen as the model learns a prior over digits without any clean input.

2.3 Time-Conditioned Flow Matching

Inject normalized time into the UNet via small FC blocks, sample a random t each batch, and train the network to predict the flow back toward clean data. Sampling starts from noise and steps t downward, showing digits emerge over epochs.

2.6 Class-Conditioned Sampling

Add one-hot class conditioning with dropout so classifier-free guidance is possible; sampling uses cfg to bias toward the requested digit. Results improve faster than the time-only model.

Reflection

Diffusion felt more forgiving than NeRFs: after wiring stride, variance, and CFG correctly, swapping prompts or masks produced stable outputs. Inpainting and SDEdit were the most satisfying because the same reverse loop could handle edits with minimal code change.
