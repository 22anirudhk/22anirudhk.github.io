CS 180 Programming Project #3A

Image Warping and Mosaicing

Anirudh Kotamraju

Overview & Pipeline

I estimate homographies from hand-picked matches, perform inverse warps with both nearest-neighbor and bilinear interpolation, and feather alpha masks to blend panoramas.

A.1: Shoot and Digitize Pictures

Each dataset was captured handheld with the camera pivoting about a fixed center of projection. I kept successive views closely spaced to preserve strong feature overlap.

A.2: Recover Homographies

I collect correspondences with a matplotlib clicker, normalize coordinates, and solve the 2n × 8 system using SVD to obtain the right-singular vector associated with the smallest singular value. Residuals land under a pixel after denormalization.

A.3: Warp the Images

Warps use inverse mapping through H⁻¹. I allocate a canvas using warped corner bounds, iterate over destination pixels, and sample the source via nearest-neighbor or bilinear interpolation. Alpha masks mark valid samples for later blending.

A.4: Blend Images into a Mosaic

Each warped image contributes RGB values weighted by a tapered alpha map (1 in the center, 0 at the borders). The final panorama normalizes the accumulated colors by accumulated weights, eliminating seams.
